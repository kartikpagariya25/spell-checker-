Behaviour

Smart mode (AI)

When you finish a sentence (or pause typing), SpellFix can ask an AI to fix spelling using the whole sentence, so it understands the meaning and tone. This sends text off your device, so it stays off until you add your own API key and turn it on.

  • Only sentences that still contain a word SpellFix doesn't recognise are sent.
  • Emails, links, @mentions, numbers and long keys are replaced by placeholders first.
  • Passwords, name / address / phone fields and code editors are never read.
  • The AI may only fix spelling. Any rewording is thrown away, and one Ctrl+Z undoes a smart fix.
  • Your key stays on this device and goes only to the provider you pick. Usage is billed to your account.
